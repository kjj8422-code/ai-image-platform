# 크몽 판매 이미지 5종 — 사용 설명서

모든 이미지 **2400 × 1800px (4:3)**. 크몽 대표이미지 권장 비율과 같고, 플랫폼이
줄여도 글자가 또렷하게 남도록 2배 해상도로 뽑았습니다.

## 1. 어디에 올리는가

| 파일 | 내용 | 올리는 위치 |
|---|---|---|
| `01-cover.jpg` | "AI로 만들고, 사람 손으로 끝냅니다" + 실제 작업물 3종 | **서비스 대표 이미지** |
| `02-quality.jpg` | 보정 전 생성 원본 + 검수 배율 + 샘플 6종 | 설명 이미지 1번 |
| `03-retouch.jpg` | AI 취약 부위 6개 → 12항목 검수 + 보정 방식 3가지 | 설명 이미지 2번 |
| `04-scope.jpg` | 작업 영역 3가지 + 실제 목업 + 납품 규격 | 설명 이미지 3번 |
| `05-package.jpg` | STANDARD / PREMIUM 2종 비교 + 공통 포함사항 | 설명 이미지 4번 |
| `06-process.jpg` | 3단계 프로세스 + 납품 사양 + FAQ | 설명 이미지 5번 |

파일 번호가 곧 업로드 순서입니다. 번호대로 올리시면 됩니다.

순서가 중요합니다. **대표 → 생성품질 → 보정 → 작업영역 → 가격 → 프로세스**가 구매 결정이
만들어지는 순서입니다. 가격을 앞으로 빼면 비교만 하고 나갑니다.

## 2. 해상도 — 4K는 안 하는 게 맞습니다 (판단 근거)

### 지금 상태

코드를 확인한 결과, Flux에 크기 파라미터를 **하나도 넘기지 않고** 있었습니다.
그래서 모델 기본값인 **1024 × 1024 정사각형** 한 종류만 나왔습니다. 4K가 아니었습니다.

이게 실제로 문제였습니다. 정사각형을 16:9로 자르면 **1024 × 576**이 되어
유튜브 권장 규격(1280 × 720)에 **미달**합니다.

### 비용 비교 (4장 1회 기준, 환율 1,380원 가정)

| 방식 | 결과 크기 | 원가 | 판단 |
|---|---|---|---|
| 그대로 두기 | 1024 정사각 | 약 **220원** | 썸네일 규격 미달 |
| **규격별 비율 지정** | 16:9 기준 1440 × 816 | 약 **220원** | ✅ **채택** |
| ultra 모델로 교체 | 최대 4MP (약 2752 × 1536) | 약 330원 | 지금은 불필요 |
| ultra + 4K 업스케일 | 4096px | 약 400~600원 | 불필요 |

**핵심은 비용이 아닙니다.** 45,000원 받는 작업에 원가 220원이든 600원이든
차이가 없습니다. 진짜 이유는 **4K를 쓸 자리가 없다**는 겁니다.

- 스마트스토어 상세페이지 — **860px 폭**
- 유튜브 썸네일 — **1280 × 720**, 게다가 업로드 **2MB 제한**
- 네이버 GFA · 메타 배너 — **1200px 내외**

4096px로 납품하면 고객이 직접 줄여야 하고, 유튜브 썸네일은 용량 제한에 걸립니다.
**고객을 불편하게 만들면서 원가만 올라가는 선택**입니다.

### 그래서 한 일

`black-forest-labs/flux-1.1-pro`는 **픽셀 수와 무관하게 장당 정액 과금**입니다.
즉 비율을 지정해도 **추가 비용이 0원**입니다. 그래서 규격 프리셋을 넣었습니다.

브랜치 `claude/format-presets`로 푸시해뒀습니다:
- `src/lib/imageFormats.ts` — 규격 프리셋(썸네일 16:9 / 상세 4:5 / 대표 1:1 / 릴스 9:16 / 배너 3:2)
- `src/app/api/generate/route.ts` — `aspect_ratio` 전달, 미지원 값은 400으로 차단
- `src/app/generate/page.tsx` — 규격 선택 버튼 추가, 기본값 썸네일

`npx next build` 통과 확인했습니다. **기본값이 정사각형 → 썸네일(16:9)로 바뀝니다.**
정사각형이 필요하면 "대표이미지"를 누르시면 됩니다.

> ⚠️ 단가와 최대 크기는 제 기준 정보입니다. `replicate.com`이 제 작업 환경에서
> 차단되어 직접 확인하지 못했습니다. 모델 페이지에서 한 번 확인해주세요.

### 언제 ultra로 올릴까

**인쇄물(전단·포스터·현수막) 의뢰가 들어올 때**입니다. 그때는 장당 $0.02만 더
내면 되고, 인쇄는 실제로 큰 원본이 필요합니다. 웹 전용인 지금은 올릴 이유가 없습니다.

## 3. 가격을 바꾸려면

`05-package.html`을 메모장으로 열고 숫자만 고치세요. 두 군데입니다.

```
<span class="num mono">45,000</span>     ← STANDARD
<span class="num mono">120,000</span>    ← PREMIUM
```

**지금 금액은 시장가 기준 예시입니다.** 팀장님 작업 시간으로 시급을 계산해서
다시 정하세요. 원가(220원)는 무시해도 될 수준이라, **가격은 곧 팀장님 시간값**입니다.

PREMIUM의 "무제한 수정"은 작업 기간 3일 내로 못 박아뒀습니다. 이 문장을 지우면
무한 수정 요청에 걸립니다.

## 4. 글자를 바꾸고 다시 뽑으려면

```bash
npm install playwright          # 최초 1회만
node render.js 05-package.html  # 고친 파일만 다시 뽑기
node export.js                  # JPG · PDF 다시 내보내기
```

`out/` 폴더에 PNG가 새로 생깁니다. `render.js`는 글자가 캔버스 밖으로
삐져나가면 **자동으로 잡아서 알려줍니다.** "정상"이면 그냥 올리시면 됩니다.

한글 폰트 Noto Sans KR이 설치돼 있어야 합니다. 없으면 글자가 □□□로 나옵니다.

### 사진이 들어간 곳 (팀장님이 생성한 원본)

`photos/` 폴더의 사진을 목업이 직접 참조합니다.

| 사진 | 쓰인 곳 |
|---|---|
| `person-1.webp` | 유튜브 썸네일 목업 (배경) |
| `person-2.webp` | 02-quality 대표 컷 + 손 부위 확대 인셋 |
| `bottle-cut-1.png` | 상세페이지 목업 제품컷 (배경 제거된 PNG) |
| `kitchen-1.webp` | 광고 배너 목업 (배경) |
| `kitchen-2 / kitchen-3 / beauty / bottle-shadow / bottle-white / bottle-cut-2` | 02-quality 샘플 갤러리 6칸 |

사진을 바꾸고 싶으면 같은 이름으로 덮어쓰고 아래를 실행하면 됩니다.

```bash
node render.js mock-thumb.html mock-detail.html mock-banner.html 01-cover.html 02-quality.html 04-scope.html
node export.js
```

목업(`mock-*.html`)은 `01-cover`와 `04-scope` 안에 iframe으로 들어가 있어서,
목업 하나만 고치면 두 판매 이미지가 같이 갱신됩니다.

### ⚠️ 확대 검수 결과 — 알고 계셔야 할 것

보내주신 사진을 4배로 확대해 손 부위를 확인했습니다. 전반적으로 좋지만
**"손가락 5개 정상"처럼 단정하는 문구는 넣지 않았습니다.** 확대하면 다음이 보입니다.

- `person-2` 오른손 — 엄지 + 네 손가락이 가장 명확합니다. **이걸 확대 인셋으로 썼습니다.**
- `person-1` 오른손 — 엄지가 과하게 두껍습니다. 크게 쓰면 지적받을 수 있습니다.
- `beauty.webp` — 세 명의 팔·손이 겹치는 구간이 해부학적으로 애매합니다. **갤러리에 작게만 넣었습니다.**

그래서 02-quality의 문구를 "손가락 5개" 같은 **완벽 주장**이 아니라
"이 배율로 확대해 검수한다"는 **과정 약속**으로 바꿨습니다. 지키기 쉽고, 반박도 안 됩니다.

**`beauty.webp`와 `person-1`을 크게 쓰는 포트폴리오는 피하세요.** 주방 컷과 제품 컷은
흠이 없어서 얼마든지 크게 써도 됩니다.

## 5. 프로필 문구 — 안전 버전 (복사해서 쓰세요)

기존 문구의 **"타사 대비 3배 높은 화질", "100%", "ZERO"** 는 객관적 근거를
요구받을 수 있는 표현입니다. 아래는 같은 세기를 유지하면서 실제로 지킬 수 있는 버전입니다.

```
남들과 똑같은 템플릿과 흔한 AI 이미지로는 클릭을 만들 수 없습니다.

의뢰하신 구도와 컨셉에 맞춰 비주얼을 새로 생성하고,
AI가 취약한 부위는 디자이너가 직접 보정해 완성도를 높입니다.

[왜 저희를 선택해야 할까요?]
· 맞춤 제작: 템플릿을 쓰지 않고 원하는 구도·비주얼을 새로 설계
· 12항목 전수 검수: 손모양·한글 텍스트·배경 경계 등 AI 취약 부위를 항목별로 점검 후 보정
· 규격별 재생성: 정사각형을 잘라 쓰지 않고, 쓰실 자리의 비율로 처음부터 생성
· 매출 중심 기획: 단순한 디자인이 아닌, 클릭과 구매전환을 부르는 비주얼 설계

[주요 작업 영역]
· 클릭률을 높이는 유튜브/SNS/블로그 썸네일
· 구매전환을 이끄는 스마트스토어/쿠팡 상세페이지 및 대표이미지
· 브랜드 인지도를 올리는 맞춤형 광고 배너/프로모션 소재

[작업 프로세스]
1. 상담 및 의뢰 — 컨셉·원고·레퍼런스 전달
2. AI 제작 & 수작업 보정 — 맞춤 비주얼 생성 및 12항목 검수 후 정밀 보정
3. 최종 완성 — 피드백 반영 후 규격에 맞는 완성 파일 제공
```

바꾼 곳은 세 군데입니다. **"3배" 삭제**, **"100%/ZERO" → "12항목 전수 검수"**,
그리고 **"규격별 재생성" 추가**(방금 코드로 구현했으므로 실제로 지킬 수 있는 약속입니다).

## 6. 다음 단계 — 실제 작업 샘플

위 5장은 판매 이미지입니다. 여기에 실제 작업 샘플이 붙으면 완성됩니다.
`/generate`에서 **규격 버튼을 누른 뒤** 아래 프롬프트를 넣으세요. 한글로 넣으면
자동 번역·보강됩니다.

| # | 규격 버튼 | 프롬프트 |
|---|---|---|
| 1 | 유튜브 썸네일 | 30대 한국 남성이 노트북을 보며 놀란 표정으로 양손을 들어올린 모습, 스튜디오 조명, 단색 배경, 상반신, 강한 명암 대비 |
| 2 | 대표이미지 | 화이트 세라믹 텀블러가 대리석 위에 놓인 제품 사진, 부드러운 자연광, 얕은 심도, 미니멀한 구성 |
| 3 | 상세페이지 | 갓 구운 크루아상 클로즈업, 버터가 흐르는 단면, 따뜻한 측광, 나무 도마 위 |
| 4 | 광고 배너 | 한국 여성 모델의 피부 클로즈업과 미니멀한 화장품 병, 파스텔 배경, 부드러운 확산광 |
| 5 | **유튜브 썸네일** | 카페에서 두 손으로 커피잔을 감싸 든 모습, 손가락이 선명하게 보이는 구도, 따뜻한 실내 조명 |

**5번이 핵심입니다.** 일부러 손이 크게 나오는 구도를 시켜서, AI가 손가락을
어떻게 망치는지 원본을 확보하는 겁니다. 그 원본과 보정본을 나란히 올리면
`02-retouch.png`의 주장이 **실물로 증명**됩니다. 크몽에서 이걸 하는 사람이 거의 없습니다.

### 표기 주의
실제 의뢰받은 작업이 아니면 **"자체 제작 샘플"로 표기**하세요. 클라이언트 실적처럼
쓰면 허위 기재입니다. 샘플이라고 적어도 구매에는 지장 없습니다 — 구매자는
"이 사람이 이 퀄리티를 뽑을 수 있는가"만 봅니다.

`01-cover`와 `03-scope`에 들어간 썸네일·상세페이지·배너도 **제작 샘플**입니다.
실제 브랜드가 아니므로 그대로 쓰셔도 문제없습니다.
