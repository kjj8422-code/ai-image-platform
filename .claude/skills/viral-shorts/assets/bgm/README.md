# 배경음악(BGM) 폴더

스토리보드가 영상 전체 분위기를 아래 4가지 기본 음악 중 하나로 골라줍니다. 같은 이름의 `.mp3`를
넣어두면 영상 길이에 맞춰 자동으로 루프되고, **나레이션이 묻히지 않도록 -15dB로 자동
감쇄**됩니다. 파일이 없으면 BGM 없이 진행됩니다.

| 파일명 | 분위기 |
|---|---|
| `mystery.mp3` | 미스터리 / 음산 / 떡밥 |
| `epic.mp3` | 웅장 / 반전 / 스케일 |
| `playful.mp3` | 장난스러움 / 코믹 |
| `dreamy.mp3` | 몽환 / 판타지 |

30초 이하 영상이라 30초~2분짜리 루프 가능한 음원이면 충분합니다.

## 현재 들어있는 곡
[FreePD](https://freepd.com/)에서 받았습니다. **CC0(퍼블릭 도메인)라 출처 표기가
필요 없고 상업적 납품에 그대로 쓸 수 있습니다.**

| 파일 | 원곡 | 고른 이유 |
|---|---|---|
| `mystery.mp3` | Asking Questions | 가장 어둡고(720Hz) 가장 성깁니다 — 말을 안 가립니다 |
| `epic.mp3` | Adventure | 음량 기복이 가장 적어(0.33) 고르게 깔립니다 |
| `playful.mp3` | Silly Boy | 가장 밝아서(3267Hz) 코믹한 톤이 납니다 |
| `dreamy.mp3` | Landra's Dream | 기복이 전체 중 가장 적고(0.27) 붕 뜨는 느낌 |

네 곡의 밝기가 720 / 1285 / 1639 / 3267Hz로 뚜렷이 갈려서, 분위기를 바꾸면
실제로 다른 영상처럼 들립니다.

> 회사망에서는 freepd.com이 차단될 수 있습니다. 그때는 archive.org의 `freepd`
> 미러에서 같은 파일을 받을 수 있습니다.

## 직접 넣는 음악 칸
웹 화면에는 기본 4곡 말고도 아래 칸이 있습니다. 파일은 들어 있지 않고, `음원넣기.bat`
으로 원하는 곡을 넣어 채웁니다. **비어 있으면 괄호 안의 기본 곡이 대신 나오고**, 제목
색·목소리 톤도 그 계열을 따릅니다. (AI는 이 칸들을 고르지 않습니다.)

| 칸 | 비어 있을 때 대신 나오는 곡 |
|---|---|
| `horror` 공포 | mystery |
| `sad` 슬픔 | dreamy |
| `upbeat` 신나는 | playful |
| `chill` 잔잔 | dreamy |
| `action` 긴박 | epic |
| `retro` 레트로 | playful |
| `my1`, `my2` 내 음악 | playful |

## 바꾸고 싶으면 (음원넣기.bat)
1. [Pixabay 음악](https://pixabay.com/music/), [FreePD](https://freepd.com/) 등에서 곡을 받습니다.
2. 프로젝트 폴더의 `음원넣기.bat`을 더블클릭(또는 받은 파일을 그 위로 끌어다 놓기).
3. 파일 → "배경음악" → 칸 번호를 고르면 끝.

넣은 곡은 `assets/user/bgm/`에 따로 저장되어 기본 곡보다 먼저 쓰입니다. 기본 곡은 그대로
남아 "빼기"로 되돌릴 수 있습니다. 곡마다 녹음 크기가 달라서 넣을 때 음량을 자동으로
맞추고(-14 LUFS), 합성할 때는 여기서 다시 -15dB 줄여 깔립니다. 5분이 넘는 곡은 앞 5분만
씁니다(영상 길이에 맞춰 반복되므로 충분합니다).

> 다른 데서 받을 때는 라이선스를 직접 확인하세요. 크몽 등 상업적 납품에는
> "상업적 이용 가능" 음원만 쓰셔야 합니다. Pixabay 음악 일부는 유튜브에서 저작권
> 알림(Content ID)이 뜰 수 있는데, 그때는 Pixabay 라이선스 페이지로 이의제기하면 됩니다.
