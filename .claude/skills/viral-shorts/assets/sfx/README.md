# 효과음(SFX) 폴더

스토리보드가 장면마다 아래 **고정된 이름 중 하나**를 골라줍니다. 여기에 같은 이름의
`.mp3` 파일을 넣어두면 해당 장면 시작 지점에 자동으로 깔립니다.
파일이 없으면 그 장면은 효과음 없이 넘어가고, 터미널에 어떤 파일이 없는지 알려줍니다.

| 파일명 | 언제 쓰이나 | 느낌 |
|---|---|---|
| `boom.mp3` | 훅 장면, 충격적인 등장 | 쿵! |
| `suspense.mp3` | 긴장 고조 | 두구두구 |
| `magic.mp3` | 판타지/마법 순간 | 샤아아~ |
| `whoosh.mp3` | 빠른 장면 전환 | 휙 |
| `pop.mp3` | 작은 전환, 포인트 | 뽁 |
| `reveal.mp3` | 반전 공개 | 짠! |
| `laugh.mp3` | 코믹 마무리 | 피식 / ㅋㅋ |

## 어디서 구하나
무료 상업용 이용이 가능한 곳(Pixabay Sound Effects, Mixkit, YouTube 오디오 보관함 등)에서
받아 위 이름으로 바꿔서 넣으면 됩니다. 길이는 0.5~2초 정도가 적당합니다.

> 라이선스는 직접 확인하세요. 크몽 등 상업적 납품에 쓰려면 "상업적 이용 가능"으로
> 표시된 음원만 사용해야 합니다.
