# 효과음(SFX) 폴더

스토리보드가 장면마다 아래 **고정된 이름 중 하나**를 골라줍니다. 여기에 같은 이름의
`.mp3` 파일을 넣어두면 해당 장면 시작 지점에 자동으로 깔립니다.
파일이 없으면 그 장면은 효과음 없이 넘어가고, 터미널에 어떤 파일이 없는지 알려줍니다.

| 파일명 | 언제 쓰이나 | 느낌 |
|---|---|---|
| `boom.mp3` | 훅 장면, 충격적인 등장 | 쿵! |
| `suspense.mp3` | 긴장 고조 | 두구두구 |
| `magic.mp3` | 판타지/마법 순간 | 샤아아~ |
| `whoosh.mp3` | 빠른 장면 전환 | 휙 |
| `pop.mp3` | 작은 전환, 포인트 | 뽁 |
| `reveal.mp3` | 반전 공개 | 짠! |
| `laugh.mp3` | 코믹 마무리 | 피식 / ㅋㅋ |

## 길이와 음량은 건드릴 필요 없습니다
파일을 그대로 넣으면 됩니다. 합성할 때 자동으로 처리됩니다.

- **길이**: 앞에서 최대 2초만 쓰고 끝을 부드럽게 줄입니다(`SFX_MAX_SECONDS`).
  17초짜리 트레일러 붐을 넣어도 영상 전체에 깔리지 않습니다.
- **음량**: 파일마다 실제 음량을 재서 같은 높이로 맞춥니다(`SFX_TARGET_RMS`).
  녹음 레벨이 제각각인 음원을 섞어 넣어도 나레이션을 덮지 않습니다.

## 현재 들어있는 파일
2026년 Sonniss GDC Game Audio Bundle(로열티 프리, 출처 표기 불필요)에서 받았습니다.
`laugh.mp3`는 등장인물 설정에 맞춰 **여성 웃음** 샘플을 골랐습니다.

> Sonniss 라이선스는 영상·게임 등 **미디어 제작용**만 허용합니다.
> **AI/머신러닝 학습에 쓰는 것은 금지**되어 있습니다.
