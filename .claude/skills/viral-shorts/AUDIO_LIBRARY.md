# 내 음원 보관함

사진 쇼츠의 **내 음원 보관함**은 로그인한 계정의 비공개 Supabase Storage를 사용합니다. 원본 음원과 PC 연결 파일은 Git에 포함하지 않습니다. 별도 DB 마이그레이션 없이 기존 `SUPABASE_SERVICE_ROLE_KEY`로 `personal-audio` 비공개 버킷을 만듭니다.

1. 사이트 `/shorts`에서 **PC 폴더 연결 파일 받기**를 누릅니다.
2. 다운로드한 `audio-sync-connection.json`을 저장소 루트의 `음원-자동동기화.bat` 위에 끌어놓습니다. 이후에는 실행기만 열면 됩니다.
3. Windows 사용자의 `Downloads/오디오모음`에 음원을 추가합니다. 실행 중에는 1분 간격으로 확인합니다. PC가 꺼졌다면 다음 실행 때 반영됩니다.

연결 파일은 음원 전용 권한이며 1년 뒤 만료됩니다. 실행기가 Windows DPAPI로 암호화해서 저장한 뒤 다운로드한 JSON은 삭제해도 됩니다. 연결 파일을 다시 받으면 이전 연결은 무효화됩니다. 사이트의 **PC 연결 해제**로 언제든 중단할 수 있습니다.

원본은 이동하거나 수정하지 않습니다. SHA-256으로 중복을 확인하고 사이트에는 96kbps MP3를 업로드합니다. 네트워크 오류가 난 파일은 다음 검사 때 재시도합니다. 삭제한 원본 때문에 사이트 음원을 자동 삭제하지 않습니다. 폴더 안의 하위 폴더도 확인하며 MP3/WAV/M4A/AAC/FLAC/OGG를 지원합니다. 업로드 한도는 변환 후 파일당 50MB, 길이는 2시간입니다.

곡명·아티스트명과 오디오의 음량·주파수·변화량에 기반한 장르/분위기 **추정값**입니다. 공식 YouTube 분류나 AI 청취 결과가 아닙니다. 사이트에서 분류와 출처 표기 문구를 수정할 수 있고, 자동 동기화가 수정을 덮어쓰지 않습니다. 라이선스는 파일에서 판단하지 않으므로 원본 배포 페이지의 조건을 확인하세요.

사진 쇼츠 프로젝트는 선택한 개인 BGM의 ID와 출처 문구를 포함합니다. 이 PC에서 `build_shorts.py`로 제작할 때 ID에 해당하는 원본을 사용하고 기존 음량 정규화·내레이션 덕킹을 적용합니다. 원본이 없거나 바뀌었다면 다른 곡으로 바꾸지 않고 오류를 알립니다. 아직 AI 영상 쇼츠의 서버 렌더에는 개인 음원이 연결되어 있지 않습니다.

로컬 상태는 `assets/user/library`에 보관합니다. `catalog.json`은 원본 위치와 분류, `분류목록`은 CSV와 장르/분위기별 M3U8 재생목록, `status.json`은 마지막 확인 결과입니다. 코드 폴더와 원본 폴더를 이동했다면 실행 경로를 수정해야 합니다.

개발 검증: `python audio_library_sync.py --scan`은 업로드 없이 분류하며, `python test_audio_library_sync.py`는 중복·추가 파일·작성 중 파일·재시도·원본 변조·연결 파일 검증을 확인합니다.
